# Plano de execução

1. Fundação: scaffold estável, design tokens, qualidade, documentação e Supabase CLI.
2. Dados: migrations multiworkspace, RLS, RPCs, Storage, Realtime e tipos gerados.
3. Fluxo vertical: cadastro/login, bootstrap do workspace, Início, nova demanda, Central, Semana e side peek.
4. Operação: histórico, notificações, busca, filtros, responsividade e estados de falha.
5. Verificação: testes unitários, políticas, E2E desktop/mobile, Axe, build e auditoria de segredos.

Cada etapa termina com um checkpoint Git sem credenciais e atualização de `docs/STATUS.md`.
